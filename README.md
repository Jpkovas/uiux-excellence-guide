## Installation via npx skills

After publishing this repository to GitHub:

```bash
npx skills add Jpkovas/uiux-excellence-guide
```

To install directly without an interactive prompt:

```bash
npx skills add Jpkovas/uiux-excellence-guide --skill uiux-excellence-guide -y
```

## Quick verification

List skills available in the repository:

```bash
npx skills add Jpkovas/uiux-excellence-guide --list
```
